# Moonlight Momos

A tiny, cozy camping trip for the browser (touch-first, made for iPad landscape). Seven days on Junkiri Danda, a misty monsoon ridge: pitch a tent, fish the lake, forage, cook by the fire, befriend a shy pangolin pup, and solve the gentle mystery of the glow on the water. Everything you see is drawn in code.

Vite + TypeScript + Phaser 3.90.

```
npm install
npm run dev        # http://localhost:5173
npm run build      # typecheck + production build to dist/
npm run smoke      # Day 1 through the debug hooks, reload, save check
npm run playtest   # the real touch paths
npm run trip       # a whole trip, Day 1 to the Trip Album
npm run shots -- m4   # milestone screenshots (iPad + phone @2x)
```
